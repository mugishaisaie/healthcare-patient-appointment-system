# Mugisha Isaie MediCare - Living Patient Appointment Experience

## Overview
This is a mobile-first, highly interactive patient appointment web application built using **React.js (Vite)** and **Tailwind CSS**. It was designed and developed to fulfill the requirements of the Front-End Development Summative Assessment.

The application serves as a **"living system"** that guides a patient through recognizing symptoms, booking an appointment, navigating their hospital visit, and completing post-visit follow-ups. The UI is designed to reduce cognitive load and provide a calming, intuitive experience for patients who may be sick or stressed.

---

## 

 Features Implemented (All 8 Required Screens)

1. **Symptom Input**: Interactive body map and guided symptom selection with a pain severity slider.
2. **Doctor Discovery**: Smart doctor suggestions based on selected symptoms, including specialty filters and AI match scores.
3. **Appointment Booking**: Clean calendar interface with available time slots and visit type toggles (In-Person/Video).
4. **Confirmation & Reminders**: Clear success animation and detailed appointment summary with reminder toggles.
5. **Hospital Arrival / Check-in**: Dynamic screen providing clear directions to the specific hospital wing and an interactive QR code for reception check-in.
6. **Live Waiting Experience**: Real-time waiting room dashboard showing a dynamic countdown ring for estimated wait time, queue position, and helpful suggestions (like grabbing a coffee).
7. **Post-Visit Summary**: A clean breakdown of the diagnosis, doctor's notes, and interactive medication prescription cards.
8. **Follow-up Reminders**: Interactive toggles for medication alarms, follow-up appointment tracking, and a hospital experience rating system.

##  Technology Stack
- **React.js** (Bootstrapped with Vite for fast builds)
- **Tailwind CSS** (Utility-first framework for precise, responsive styling)
- **React Router DOM** (For seamless, single-page client-side navigation)
- **Lucide React** (For modern, clean SVG iconography)


##  Design System
- **Primary Color**: Calm Teal/Blue (`#2B92B1`) — Chosen for its calming, trustworthy, and accessible properties in healthcare.
- **Typography**: Clean Sans-serif — Optimized for readability, especially for first-time smartphone users.
- **Structure**: Card-based layouts with soft shadows and clear visual hierarchy to reduce cognitive load.
- **Animations**: Soft state transitions and interactive micro-animations to make the app feel "alive" and responsive to user actions.
